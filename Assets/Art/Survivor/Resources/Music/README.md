# 배경 음악 넣는 곳

이 폴더에 아래 이름으로 음원을 넣으면 게임이 알아서 튼다 (확장자 무관: .ogg 권장, .mp3/.wav 가능).

| 파일 이름 | 언제 |
|---|---|
| `title` | 메인 화면 |
| `field` | 한 판 진행 중 |
| `boss` | 불가살이 등장 컷신이 끝난 뒤 |
| `victory` | 보스를 물리친 뒤 결과 화면 |

음원은 재배포 가능한 라이선스인지 확인하고 넣는다 (CLAUDE.md "주의"). 출처·라이선스는 이 표 아래에 적어 둔다.

## 출처 (2026-11-10, 임시 — 어울리지 않으면 바꾼다)

모두 OpenGameArt.org의 **CC0(퍼블릭 도메인)** — 재배포·상업 이용 가능, 출처 표기 의무 없음 (감사의 뜻으로 적어 둔다).

| 파일 | 원곡 | 작가 | 라이선스 | 페이지 |
