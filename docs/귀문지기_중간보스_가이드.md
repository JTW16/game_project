# 귀문지기(중간 보스) 넣기 가이드

> 큰 귀문을 부수면 나오는 몬스터(귀문지기)에 진짜 그림과 공격을 넣을 때 보는 문서다.
> 규칙의 기준은 [`설계서.md`](../설계서.md) 4장 "귀문 부수기"이고, 이 문서는 **코드 어디를 바꾸면 되는지**만 정리한다. 수치는 모두 가안이다.

## 1. 지금 어떻게 돌아가나

```
1 · 3 · 5 · 7분  큰 귀문이 퇴마사 근처 화면 밖에서 솟음        SvSpawner.OpenNextGate → SvGame.OnGateOpened
       ↓ 무기로 때려 부숨 (체력 900 × (1 + 열린 시각/240초))
  무너짐: 보석 40 + 정예 아이템 + 귀문지기 등장               SvGame.OnGateBroken → SvSpawner.SpawnGateKeeper
       ↓ 귀문지기를 잡음
  핵심 비급 창 하나 (가진 무기·기술 중 핵심이 없는 것 3장)     SvGame.OnEnemyKilled → OnGateKeeperDown → Progress.AddCoreReward
```

- **지금 귀문지기는 임시로 "크게 키운 정예"다** — `SvEnemyKind.Elite`, 체력 = 정예 체력 × 3, 그림 × 1.3 (`SvSpawner` 인스펙터 `keeperHpMul` · `keeperScale`).
- 공격도 정예 것(`SvEliteAttack`: 빨간 부채꼴 예고 → 할퀴기, 패링 가능)을 그대로 쓴다.
- 9분에 보스가 이미 나왔으면 귀문이 무너져도 귀문지기는 나오지 않는다 (`OnGateBroken`의 `if (Spawner.BossSpawned) return;`).

## 2. 손대는 곳 (한 곳에 모아 둠)

| 하고 싶은 것 | 파일 · 위치 |
|---|---|
| **귀문지기를 만드는 곳** — 여기만 바꾸면 된다 | `Assets/Scripts/Survivor/SvSpawner.cs` → `SpawnGateKeeper(Vector2 at)` |
| 귀문지기 표시 (보상 판정에 씀) | `SvEnemy.cs` → `IsGateKeeper`, `MakeGateKeeper(float scale)` |
| 등장 알림 · 연출 | `SvGame.cs` → `OnGateBroken` (끝부분 `Hud.Popup(... 귀문지기가 나온다)`, `SvFoeVfx.EliteArrive`) |
| 쓰러졌을 때 보상 | `SvGame.cs` → `OnGateKeeperDown` (핵심 비급 창 — **건드리지 않아도 된다**) |
| 체력 · 크기 수치 | `SvSpawner` 인스펙터 `keeperHpMul`, `keeperScale` (씬 생성 뒤 씬에 저장됨) |

> ⚠️ **새 몬스터로 바꿔도 `MakeGateKeeper()`는 꼭 불러야 한다.** `IsGateKeeper`가 참이어야 잡았을 때 핵심 비급 창이 뜬다.

## 3. 방법 A — 그림만 바꾸기 (정예 공격은 그대로)

공격 방식은 정예와 같아도 되고 **생김새만 다르게** 하고 싶을 때. 코드 변경이 가장 적다.

1. **그림 파일** (Codex로 뽑음, 요청서는 [`image_request_v2.md`](../image_request_v2.md)에 새 절로 추가)
   - 프레임 그림: `ArtSource/v2/yokai/gate_keeper/` 에 `base.png` · `move.png`(4칸) · `attack.png`(6칸) · `death.png`(3칸) — 정예(`yokai/elite_changgwi/`)와 같은 칸 수 · 같은 배경 규칙.
   - 부위 그림(뼈대용, 선택): `ArtSource/v2/rig_mobs/gate_keeper.png` — 정예 시트(`rig_mobs/elite.png`)와 같은 4×3 칸 배치.
2. **가공 스크립트에 한 줄씩**
   - `Tools/survivor_art/cut_sprites.py`: 정예 줄(`('elite', 'Elite', 420, [...])`, 52번째 줄 근처)을 복사해 `('keeper', 'Keeper', …)`로, 경로를 `yokai/gate_keeper/...`로.
   - (뼈대) `Tools/survivor_art/cut_mobs.py`: `KINDS`에 `'keeper'` 항목 — `'elite'`를 복사한 뒤 부위 점(원본 점 · 시트 점)을 새 그림에 맞춰 다시 잰다.
3. **그림 묶음에 칸 추가**
   - `SurvivorArt.cs`: `public SvMobArt elite = new();` 아래에 `public SvMobArt keeper = new();`
   - `Editor/SurvivorSceneBuilder.cs`: `art.elite = Mob("Elite", "elite", 2.9f, 6f);` 아래에 `art.keeper = Mob("Keeper", "keeper", <키>, <fps>);`
4. **입혀 주기** — `SvEnemy.MakeGateKeeper()` 안에서 정예 그림 대신 `art.keeper`로 갈아입힌다 (짙은 변종이 그림을 갈아입는 `MakeFierce()`가 본보기).
   - 뼈대를 쓰면 `SvMobRig.cs`의 `NameOf()`가 종류로 이름을 정하므로 귀문지기면 `"keeper"`를 돌려주게 한다 (예: `SvMobRig`이 `SvEnemy.IsGateKeeper`를 보고 고름).
5. 실행: `python -I Tools/survivor_art/cut_sprites.py` → (뼈대) `python -I Tools/survivor_art/cut_mobs.py` → 씬 생성.

## 4. 방법 B — 새 적 종류 (자기만의 공격 · 패턴)

중간 보스다운 **고유 공격**을 넣고 싶을 때.

1. `SvEnemy.cs`
   - `enum SvEnemyKind`에 `GateKeeper` 추가.
   - `IsBig`에 넣는다 (`IsElite || IsBoss || Kind == SvEnemyKind.GateKeeper`) — 화면 밖 화살표(`SvHud`), 멀어져도 다시 놓이지 않음(`SvSpawner.RecycleFar`), 몸 빛 테두리(`SvMobRig`), 벽력부 피해(`SvPickup`), 잡몹 공격 동작 제외 등이 "큰 적"을 이 값으로 판단한다.
   - 생성 `switch`(정예 `case SvEnemyKind.Elite:` 근처)에 몸 반지름 · 그림 크기 · 무게.
   - 공격 컴포넌트: 정예처럼 `SvEliteAttack`을 붙이거나(192번째 줄 근처), 새 공격 클래스(예: `SvKeeperAttack`)를 만들어 붙인다. 보스 패턴(`SvBoss`)이 큰 본보기다.
   - 그림 선택 `switch`(`SvEnemyKind.Elite => art.elite` 근처)에 `GateKeeper => art.keeper`.
2. `SvSpawner.cs`
   - `Spawn()`의 체력 `switch`에 `case SvEnemyKind.GateKeeper:` (체력 · 속도 · 닿는 피해 · 경험치).
   - `SpawnGateKeeper()`에서 `Spawn(SvEnemyKind.GateKeeper, at)` 후 **`e.MakeGateKeeper(...)`**.
3. `SvGame.OnEnemyKilled`: 지금은 `if (e.IsElite) { 보석 50 + 정예 아이템 }` 블록이 귀문지기에도 적용된다. 새 종류면 이 블록을 타지 않으므로, 떨굴 것(보석 · 아이템)을 `OnGateKeeperDown`에 넣는다.
4. 미니맵(`SvMinimap`)은 정예 · 보스만 아이콘으로 찍는다 — 필요하면 귀문지기 아이콘 추가.
5. 그림 파일 · 가공 · 씬 생성은 방법 A의 1~3, 5와 같다. `SvMobRig.NameOf()`에 `SvEnemyKind.GateKeeper => "keeper"`.

## 5. 지켜야 할 것 (설계서 규칙)

- **빨강은 적 공격 경고 전용**이다. 몸 · 이펙트 색에 빨강을 쓰지 않는다 (정예 = 먹보라, 보스 = 쇳빛 · 주황).
- **보이는 예고 테두리 = 맞는 테두리.** 예고는 `SvWarn`(붉은 부적진)을 쓴다.
- 패링 가능한 공격은 예고가 빨개지는 순간에 맞춘다 (`SvEliteAttack.CueRed` 참고).
- 새 그림 · 소리는 재배포 가능한지 확인한다.
- 수치는 인스펙터로 노출하고 "가안"으로 적는다. 정해지면 설계서 4장 "귀문 부수기"를 고친다.
